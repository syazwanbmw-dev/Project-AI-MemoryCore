## 23:10 — Slip Keputusan Ujian Dalaman + Filter Tahun

**Projek:** mypwa-v2 (eNilai — sistem rekod prestasi murid)

### Apa yang dibuat

Sesi malam ni sepenuhnya fokus pada `laporan-ujian.html` — dua feature baru selesai dan live production dalam masa lebih kurang 2 jam.

**Feature 1: Slip Keputusan Ujian Dalaman**

Implement spec yang siap semalam. Slip cetak individu murid — portrait A4, layout rasmi.

- Backend extend `GET /api/ujian-markah/laporan` — tambah `m.no_kad` dan `m.jantina` dalam SELECT. Tiada migration, tiada endpoint baru.
- Frontend: SVG printer icon hijau per-murid (desktop table + mobile card), butang "Cetak Semua Slip" dalam toolbar.
- `kiraRankingSlip()` — kira purata dan kedudukan kelas & keseluruhan client-side. Rank keseluruhan merentasi semua murid dalam ujian, rank kelas dalam kelas_id yang sama.
- `buildSlipHTML()` — satu fungsi untuk per-murid DAN batch (DRY). Terima murid object + rankMap + subjek_list.
- `wrapSlipHTML()` — wrapper HTML lengkap, load Plus Jakarta Sans, print CSS portrait A4.
- Fix `cetakLaporan()`: clone table dulu, strip semua `.no-print` elements sebelum inject ke print window. Root cause: window baru tiada CSS `.no-print { display:none }`.

Banyak polish kecil sepanjang sesi: jantina uppercase (LELAKI/PEREMPUAN), normalize robust `.charAt(0).toUpperCase()`, semua teks hitam dalam slip, buang border, bold nama ujian/sesi, font Plus Jakarta Sans.

**Feature 2: Filter Tahun dalam Laporan Ujian**

Soalan dari master: "jika ujian melibatkan murid tahun 4, 5 dan 6 — bagaimana laporan dipapar bila pilih semua kelas?" Diagnose: `subjek_list` akan gabungkan semua tahun, murid dapat kolum kosong untuk subjek tahun lain.

Penyelesaian: tambah dropdown Tahun antara Sesi dan Kelas.

- `filter-grid-4` → `filter-grid-5` (Ujian | Sesi | Tahun | Kelas | Button)
- `filterTahunDropdown()` — populate tahun berdasarkan sesi + `_tahunList`. Auto-select jika satu tahun sahaja.
- "Semua Kelas" kini bermaksud semua kelas dalam tahun yang dipilih.
- Backend: `?tahun=` param → `WHERE k.tahun = ?` untuk allKelas query.
- Slip functions: guna `_ujianData.subjek_list` (year-filtered) untuk display slip, allSubjek untuk ranking. Ranking masih tepat merentasi semua tahun.

### Keputusan teknikal penting

1. **Ranking slip lintas tahun** — `kiraRankingSlip()` exclude `undefined` dari purata secara automatik (bukan null check sahaja). Murid tahun 4 hanya dikira berdasarkan subjek tahun 4, begitu juga tahun lain. Fair dan betul tanpa logic tambahan.

2. **Dua subjek_list berbeza** — allSubjek (semua tahun) untuk ranking, `_ujianData.subjek_list` (year-filtered) untuk display dalam slip. Pemisahan ini penting untuk slip yang bersih.

3. **Print window + no-print** — `outerHTML` clone tidak bawa CSS context. Lesson: jangan assume class akan berfungsi dalam window baru. Clone + strip adalah pattern yang betul.
